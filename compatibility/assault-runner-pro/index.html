Setup notes

  • Power on the console and start a treadmill session so live FTMS workout data is available.

Known limitations

  • A customer console variant used an additional FTMS flag and required a firmware parsing correction now included in version 4.0.1.

What “compatible” means

RunBridge can relay the speed and distance data this treadmill reports. It cannot correct a treadmill whose belt speed or console distance is itself miscalibrated.
