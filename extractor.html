Download your RunBridge logs

Plug in your RunBridge dongle, connect, and download a log file you can email to support. This runs locally in your browser. No data is uploaded anywhere.

Ready
Use Chrome or Edge. When prompted, select RunBridge (or the USB serial device).
Quickstart
  1. Plug the RunBridge dongle into USB.
  2. Click Connect & Download.
  3. Select the device from the popup list (the correct device should be highlighted if you've connected before).
  4. When it finishes, email the downloaded file to support.
If you're asked what to select: pick the device that mentions RunBridge, nRF52, or USB Serial.
Troubleshooting
  • If the button does nothing, your browser may not support Web Serial.
  • Try a different USB port/cable, then refresh the page and try again.
  • If the download freezes (progress stops), click Rescue Partial Log to save what we have so far.
