Update RunBridge Firmware

Flash the latest features and fixes to your RunBridge device via USB Drag-and-Drop.

Step 1
Download the latest firmware file.
Download Firmware (CURRENT.UF2)
Step 2: Install Update
1. Plug in RunBridge.
2. Double-tap Reset quickly to enter update mode.

3. A new USB drive will appear on your computer (often named RUNBRIDGE, XIAO-SENSE, or just USB Drive). Open this drive.
4. Drag the downloaded CURRENT.UF2 file into it (replace existing file if asked).
Troubleshooting
  • Drive not showing? Try a different USB cable or adjust your double-tap speed.
  • Replacing file? Yes, it is safe to overwrite the existing CURRENT.UF2.
  • Device stuck in DFU? If the LED stays pulsing, simply drag the CURRENT.UF2 file onto the drive again to restore it.
